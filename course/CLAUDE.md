# Диалог «Курс»

Этот диалог занимается только курсом. Блог и продвижение ведутся в отдельном диалоге (папка `blog/`).

## Задача
Базовый офлайн-курс татуировки с нуля для одной ученицы, декабрь 2026, 13 занятий: 12 на синтетической коже, 13-е — первая работа на человеке (модели).
Основа — `course/programma-kursa.md`.

## Что делаем
1. Расписываем каждый урок подробно в отдельном файле: `course/uroki/urok-01.md` … `urok-13.md`.
   В каждом: цель, план по времени, теория (полный текст, который Аня может рассказывать), практика по шагам, типичные ошибки ученицы, домашка, список материалов на занятие, чек-лист «урок усвоен».
   Ане конспект присылаем PDF-файлом A4 (`python3 course/uroki/make-konspekt-pdf.py course/uroki/urok-NN.md` → `urok-NN.pdf`): .md на iPad читать неудобно. Шрифты в PDF только статические (PT Sans, Oswald), вариативные (Manrope) Chromium встраивает как Type 3, и в приложениях Apple они ломаются.
2. Для каждого урока делаем отдельную презентацию для ученицы (8–15 слайдов) в стиле подарочных сертификатов Ани: голубой аэрограф, оранжевые гранж-заголовки с белым свечением (Rubik Dirt), белые стикеры-карточки (Oswald, Manrope), оранжевые слайды со звездой, стикеры-маскоты; на обложке круглый логотип `img/logo.png` и надпись `img/wordmark.png` (официальные файлы Ани). Шаблон — `course/prezentacii/urok-01.src.html`, картинки — `course/prezentacii/img/` (в готовый HTML вшиваются base64, чтобы файл открывался сам по себе). Презентацию публикуем ссылкой, чтобы её можно было открыть с планшета и переслать ученице. Ссылки записываем в `course/prezentacii.md`. Сборка: `python3 course/prezentacii/build.py - <шаблон.src.html> <итог.html> course/prezentacii/img`, PDF 16:9: `node course/prezentacii/make-pdf.js <итог.html> <папка>` и `python3 course/prezentacii/make-pdf.py <папка> <итог.pdf>`. PDF собирается из картинок слайдов (3200×1800), а не печатью из браузера: векторный PDF из Chromium ломается в приложениях Apple (пропадают шрифты, свечение и тени).
3. Дополнительно по запросу: памятки для ученицы (гигиена, иглы, уход), сертификат, договор/правила курса, расписание с датами.

## Календарь
- Google Calendar подключён. Занятия курса вносим в календарь «Курс» (найти через list_calendars). Если его ещё нет — попроси Аню создать (calendar.google.com → «Другие календари» → «+» → «Создать календарь»).
- Каждое занятие — событие с временем: «Курс · Урок N — тема», в описании — ссылка на презентацию и список материалов. Перед этим проверь основной календарь Ани на пересечения с клиентами.
- Ничего не создавать и не менять в календаре без «да» от Ани.

## Правила
- **Порядок работы над уроком (правило Ани):** сначала только текст конспекта (`urok-NN.md`, присылать карточкой). Презентацию, ссылку и любые PDF делаем ТОЛЬКО после согласования текста и явного сигнала Ани. Экономить токены: без лишних проверок и длинных отчётов.
- Пиши по-русски, просто и дружелюбно, без канцелярита.
- Медицинские и санитарные темы — аккуратно и без выдуманных норм; где нужно, советуй сверить с местными требованиями Грузии.
- После каждого изменения коммить и пушь, присылай Ане изменённый файл карточкой.
- Расписание: `course/raspisanie.md` (старт 1 декабря, внесено в календарь «Курс»).
- Ученица умеет рисовать: базу рисунка пропускаем, урок 4 — только специфика эскиза для тату.
