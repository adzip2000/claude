# Диалог «Курс»

Этот диалог занимается только курсом. Блог и продвижение ведутся в отдельном диалоге (папка `blog/`).

## Задача
Базовый офлайн-курс татуировки с нуля для одной ученицы, декабрь 2026, 13 занятий: 12 на синтетической коже, 13-е — первая работа на человеке (модели).
Основа — `course/programma-kursa.md`.

## Что делаем
1. Расписываем каждый урок подробно в отдельном файле: `course/uroki/urok-01.md` … `urok-13.md`.
   В каждом: цель, план по времени, теория (полный текст, который Аня может рассказывать), практика по шагам, типичные ошибки ученицы, домашка, список материалов на занятие, чек-лист «урок усвоен».
2. Для каждого урока делаем отдельную презентацию для ученицы (8–15 слайдов): тёмная эстетика, барокко, как у Ани в Instagram. Презентацию публикуем ссылкой, чтобы её можно было открыть с планшета и переслать ученице. Ссылки записываем в `course/prezentacii.md`.
3. Дополнительно по запросу: памятки для ученицы (гигиена, иглы, уход), сертификат, договор/правила курса, расписание с датами.

## Календарь
- Google Calendar подключён. Занятия курса вносим в календарь «Курс» (найти через list_calendars). Если его ещё нет — попроси Аню создать (calendar.google.com → «Другие календари» → «+» → «Создать календарь»).
- Каждое занятие — событие с временем: «Курс · Урок N — тема», в описании — ссылка на презентацию и список материалов. Перед этим проверь основной календарь Ани на пересечения с клиентами.
- Ничего не создавать и не менять в календаре без «да» от Ани.

## Правила
- Пиши по-русски, просто и дружелюбно, без канцелярита.
- Медицинские и санитарные темы — аккуратно и без выдуманных норм; где нужно, советуй сверить с местными требованиями Грузии.
- После каждого изменения коммить и пушь, присылай Ане изменённый файл карточкой.
- Неизвестно до сих пор: дата старта, умеет ли ученица рисовать, кто будет моделью на 13-м занятии. Спроси, когда это влияет на работу.
